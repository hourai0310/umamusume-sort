# ウマ娘 楽曲ソート（ファンメイド）

静的なHTML/CSS/JavaScriptだけで動く、GitHub Pages向けの楽曲ランキングサイトです。

## 公開方法
1. GitHubで新しいリポジトリを作成（例: `umamusume-song-sort`）。
2. `index.html` `style.css` `app.js` `README.md` をリポジトリ直下にアップロード。
3. リポジトリの **Settings → Pages** を開く。
4. **Deploy from a branch** を選び、Branch は `main`、Folder は `/ (root)` にして Save。
5. 表示されるURLを開けば公開完了です。

## 注意
- 収録曲は初期サンプルです。網羅性を保証するものではありません。画面から曲を追加できます。
- ブラウザの localStorage に進行状況を保存します。同じ端末・同じブラウザで再開できます。
- 画像保存はブラウザ内で生成します。
- 公式画像・音源は使用していません。ファンメイドの非公式サイトです。
